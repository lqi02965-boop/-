# 人脸识别智能考勤打卡系统

> 基于 **InsightFace + MediaPipe** 的桌面端智能考勤系统：人脸识别签到、眨眼活体防伪、考勤状态自动判定、管理员二级鉴权、Excel 报表一键导出，全流程闭环可用。

## 功能特性

- **高精度人脸识别**：InsightFace 提取 512 维人脸特征向量，余弦相似度匹配，识别相似度百分比实时显示
- **活体防伪检测**：MediaPipe 468 点面部关键点 + EAR（Eye Aspect Ratio）眨眼检测，要求自然眨眼 2 次通过验证，防御照片/屏幕攻击
- **流程状态锁**：全局状态机强制"摄像头开启 → 人脸识别 → 活体检测 → 确认打卡"顺序执行，跳步直接拦截提示
- **考勤状态自动判定**：按上班/下班时段自动计算并标注 正常 / 迟到 / 早退 / 加班时长
- **管理员二级鉴权**：密码登录 + 管理员人脸识别登录双通道；支持修改密码、重新录入管理员人脸
- **数据持久化**：SQLite 存储员工档案（含特征向量）与打卡流水
- **Excel 报表导出**：员工档案表、考勤打卡记录表一键导出 .xlsx（Pandas + OpenPyXL）

## 技术栈

| 层 | 技术 |
|---|---|
| GUI | PySide6 (Qt for Python) |
| 人脸识别 | InsightFace（512 维特征 + 余弦相似度） |
| 活体检测 | MediaPipe Face Mesh（468 关键点）+ EAR 眨眼算法 |
| 图像处理 | OpenCV |
| 存储 | SQLite |
| 报表 | Pandas + OpenPyXL |

## 核心实现说明

### EAR 眨眼活体检测

MediaPipe 输出 468 个面部关键点后，取左右眼各 6 个关键点计算眼睛纵横比（EAR）；当 EAR 连续低于阈值再回升记一次有效眨眼，眨眼 2 次判定为活体。照片、屏幕重放不会产生 EAR 变化曲线，从而实现防伪。

### 双引擎识别管线

InsightFace 负责身份（谁来了），MediaPipe 负责防伪（是不是真人），两者结果都通过才允许打卡——单一引擎被绕过的风险由另一引擎兜底。
